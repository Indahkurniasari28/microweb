Pengenalan MICROWAT

Apa itu dan bagaimana cara kerjanya

MICROWAT adalah sistem monitoring real-time degradasi limbah zat warna menggunakan teknologi UV-Vis Spektrometri. Sistem ini mengintegrasikan hardware fisik (Raspberry Pi + Avantes Spectrometer + ESP32) dengan dashboard web untuk memantau efisiensi degradasi fotokatalitik.

dashboard

Dashboard

Halaman utama monitoring real-time

📊 Kartu KPI (4 Metrik Utama)

Degradasi (%)

Persentase degradasi zat warna: ((C₀ - Cₜ) / C₀) × 100. Semakin tinggi = semakin baik. Ditampilkan dengan lingkaran SVG animasi.

Absorbansi (a.u.)

Nilai absorbansi dari spektrometer Avantes. Semakin rendah = larutan semakin bening.

Konsentrasi (ppm)

Dihitung via Hukum Beer-Lambert: C = A / (ε × b). ε = koef. extinc., b = panjang jalur.

Status Sistem

Indikator koneksi Hardware (Spectrometer), MQTT (ESP32), dan status pengukuran (Active/Idle/Complete).

⚙️ Quick Actions

science

Device

Status hardware & kontrol pengukuran kuvet

📊 KPI Bar (4 Metrik Atas)

Active Devices

Jumlah perangkat yang terhubung dari total 2 perangkat (Raspberry Pi 5 + Avantes UV Spektrofotometer).

Monitoring Time

Jam:Menit:Detik yang telah berjalan sejak halaman Device dibuka. Timer berjalan terus selama sesi aktif.

Konsentrasi (ppm)

Konsentrasi limbah terkini dari pengukuran terakhir spektrofotometer, dihitung via Hukum Beer-Lambert.

Degradasi (%)

Persentase degradasi limbah dari pengukuran terakhir. Formula: ((C₀ − Cₜ) / C₀) × 100.

🖥️ Hardware yang Dipantau

Raspberry Pi 5

Controller utama sistem. Menampilkan CPU usage, RAM usage, latency jaringan, dan system load. Status ONLINE/OFFLINE diperbarui otomatis via WebSocket. Klik kartu untuk melihat detail lengkap (Device Detail).

• CPU: Cortex-A76 Quad-core • RAM: 8 GB LPDDR4X • OS: Raspberry Pi OS Bookworm • Koneksi: Server via Socket.io

Avantes UV Spektrofotometer

Instrumen pengukuran absorbansi UV-Vis. Menampilkan Peak λ, nilai absorbansi terakhir, status USB, dan capture progress. Terhubung ke RPi via USB. Status CAPTURING saat pengukuran berjalan.

• Rentang: 360–2500 nm • Koneksi: USB ke RPi 5 • Peak λ: 664 nm (Methylene Blue) • Status: CAPTURING / STANDBY

water_pump Kontrol Pengukuran

Tiga tombol kontrol manual untuk aliran limbah dan proses pengukuran spektrofotometrik. Sistem juga berjalan otomatis setiap 15 menit.

water_pump

Isi (Fill)

Mengaktifkan water pump untuk memompa limbah dari gelas beaker ke dalam kuvet spektrofotometer. Tekan saat siap memulai siklus pengukuran.

biotech

Ukur (Measure)

Memicu Avantes UV Spektrofotometer untuk mengukur panjang gelombang dan absorbansi sampel di dalam kuvet. Tekan setelah proses Isi selesai. Hasil langsung tampil di Dashboard dan Analytics.

output_circle

Kosong (Empty)

Membuang limbah yang sudah diukur dari kuvet. Kuvet dikosongkan agar siap untuk siklus pengukuran berikutnya. Tekan setelah proses Ukur selesai.

Alur kerja: Isi → Ukur → Kosong → ulangi setiap 15 menit. Setiap siklus menghasilkan satu titik data absorbansi/konsentrasi/degradasi.

🔄 Live Refresh & Export Report

  • toggle_onLive Refresh – Toggle di pojok kanan atas halaman. Saat aktif (biru), KPI bar dan status kartu diperbarui otomatis setiap kali ada data baru.
  • downloadExport Report – Tombol di pojok kanan atas mengunduh seluruh data history sebagai file CSV.
  • open_in_newTap untuk detail – Setiap kartu perangkat (RPi / Avantes) bisa diklik untuk membuka halaman Device Detail dengan telemetri dan log lengkap.
database

Data History

Riwayat semua pengukuran & export data

📁 Tabel Data

Menampilkan semua pengukuran historis dengan kolom: Waktu, Absorbansi, Konsentrasi, Degradasi (%), dan Status (SAFE jika degradasi ≥70%, NOT SAFE jika <70%).

Tampil 20 baris per halaman. Gunakan tombol ← → di bawah untuk navigasi antar halaman.

🔽 Filter & Export

  • filter_altFilter Tanggal – Pilih dari dan sampai tanggal, klik Filter untuk menyaring data
  • labelFilter Jenis Zat Warna – Tombol ALL / RC (Rhodamine C) / MG (Malachite Green) / MB (Methylene Blue) di header halaman
  • downloadExport CSV – Unduh seluruh data (yang sudah difilter) sebagai file CSV. Juga bisa klik CSV di kolom Aksi untuk export satu baris.
  • downloadExport Data (Sidebar) – Tombol di sidebar bawah akan langsung mengunduh semua data history sebagai CSV.
settings

Settings (User)

Profil akun & parameter sistem

👤 Tab Profile

Update nama, organisasi, dan lokasi Anda. Email tidak bisa diubah (readonly). Klik Save Profile untuk menyimpan.

⚗️ Tab Parameters

Konfigurasi parameter kalkulasi Beer-Lambert:

C₀ Awal (ppm)
Konsentrasi larutan awal sebelum proses degradasi dimulai
Wavelength (nm)
Panjang gelombang pengukuran spektrometer (default: 254 nm)
Koef. Extinc.
Molar extinction coefficient zat warna (L/mol·cm)
Path Length (cm)
Panjang jalur optik kuvet spektrometer

Klik Simpan Parameter — parameter langsung diterapkan ke semua kalkulasi baru.

admin_panel_settings

Fitur Admin

Akses eksklusif administrator sistem

⚠️ Panel admin hanya muncul jika email mengandung kata admin (misal: admin@lab.com)

group User Management

  • Lihat semua user — tabel dengan nama, email, institusi, role, status, tanggal bergabung
  • Search & Filter — cari berdasarkan nama/email, filter berdasarkan role (Admin/User) atau status (Active/Pending/Blocked)
  • Edit Role — klik ikon ✏️ untuk mengubah role user (User → Admin atau sebaliknya)
  • Block/Unblock — klik ikon 🚫 untuk memblokir atau mengaktifkan kembali user
  • Hapus User — klik ikon 🗑️ untuk menghapus akun (akan minta konfirmasi)
  • Review Pending — banner di atas menampilkan jumlah user menunggu approval. Klik REVIEW ALL untuk mengaktifkan semua sekaligus

receipt_long Log Detail

  • Event Log Table — semua event sistem: Measurement, System Event, Calibration, Error dengan timestamp dan status (NOMINAL/WARNING/ANOMALY)
  • Filter Log — filter berdasarkan tanggal dan tipe event
  • Detail Drawer — klik baris mana saja untuk membuka panel detail di kanan: nilai absorbansi, konsentrasi, degradasi, dan kolom catatan admin
  • Flag Anomaly — tandai entry sebagai anomali dari panel detail
  • Export CSV — unduh seluruh log event sebagai file CSV

tune Instrument Config

  • Microwave Emitter — atur rentang daya (W), intensitas saat ini via slider, toggle auto power control
  • UV Lamp Assembly — atur flux density (μW/cm²), wavelength, lihat estimasi sisa umur lampu
  • Spectrometer Calibration — set C₀, path length, extinction coefficient, dan wavelength pengukuran
  • Safety Thresholds — batas emisi partikel max (ppm) dan batas minimum degradasi sebelum alarm
  • Save Config — simpan semua perubahan ke server sekaligus

tips_and_updates

Tips & Navigasi

Cara penggunaan yang efisien

🧭 Navigasi Sidebar

  • chevron_rightKlik menu di sidebar kiri untuk berpindah halaman. Halaman aktif ditandai warna biru dengan font tebal.
  • chevron_rightTombol Export Data di sidebar selalu tersedia untuk mengunduh data history kapan saja.
  • chevron_rightStatus koneksi (Online/Offline) terlihat di header kanan atas — hijau = terhubung ke server.

🔔 Notifikasi

Klik ikon lonceng 🔔 di header untuk membuka panel notifikasi. Notifikasi muncul otomatis saat:

  • Data baru masuk dari spektrometer
  • Koneksi ke server terputus atau terhubung kembali
  • Pengukuran dimulai, dihentikan, atau direset
  • Data berhasil disimpan atau terjadi error
  • Data simulator berhasil dikirim

🌓 Mode Tampilan

Klik ikon light_mode / dark_mode di header kanan atas untuk beralih antara Dark Mode (gelap, cocok di lab redup) dan Light Mode (terang, cocok di lingkungan cerah). Pilihan tersimpan otomatis.

📱 Progressive Web App (PWA)

MICROWAT bisa di-install sebagai aplikasi di perangkat Anda:

  • Chrome/Edge Desktop — klik ikon install (⊞) di address bar
  • Android Chrome — ketuk "Add to Home Screen" di menu browser
  • iOS Safari — ketuk Share → Add to Home Screen

💡 Tips Pengukuran Optimal

  • 1.Set C₀ (konsentrasi awal) di Settings sebelum memulai pengukuran pertama
  • 2.Gunakan mode simulasi di Dashboard untuk memahami alur data sebelum koneksi hardware
  • 3.Export data ke CSV secara berkala sebagai backup, terutama setelah sesi panjang
  • 4.Gunakan filter tanggal di History untuk membandingkan sesi berbeda hari
  • 5.Status SAFE (degradasi ≥70%) menandakan proses degradasi berhasil. Target minimal 70%.
