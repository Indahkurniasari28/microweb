Introduction to MICROWAT

What it is and how it works

MICROWAT is a real-time dye wastewater degradation monitoring system using UV-Vis Spectrometry technology. The system integrates physical hardware (Raspberry Pi + Avantes Spectrometer + ESP32) with a web dashboard to track photocatalytic degradation efficiency.

Concentration is calculated from absorbance using A = εbc

Real-time WebSocket

Sensor data is sent via Socket.io every time there's a new update

Login & Account

How to sign in, register, and reset your password

key Login

  1. Enter your email and password in the login form
  2. Click the Sign In button

  2. Enter your registered email

dashboard

Dashboard

The main real-time monitoring page

📊 KPI Cards (4 Main Metrics)

Degradation (%)

Dye degradation percentage: ((C₀ - Cₜ) / C₀) × 100. Higher = better. Shown with an animated SVG circle.

Absorbance (a.u.)

Absorbance value from the Avantes spectrometer. Lower = clearer solution.

Concentration (ppm)

Calculated via the Beer-Lambert Law: C = A / (ε × b). ε = extinction coefficient, b = path length.

System Status

Connection indicators for Hardware (Spectrometer), MQTT (ESP32), and measurement status (Active/Idle/Complete).

⚙️ Quick Actions

play_circle

Start Measurement

Starts a new measurement session. The system begins receiving and processing data from the spectrometer in real time.

stop_circle

Stop Measurement

Stops the session that's currently running. Data already received stays saved in history.

restart_alt

Reset Data

Clears the current session's data. Data on the server stays safe — only the display is reset.

Automatically generates simulated data for testing without physical hardware.

Device

Hardware status & cuvette measurement controls

📊 KPI Bar (Top 4 Metrics)

Active Devices

Number of connected devices out of a total of 2 devices (Raspberry Pi 5 + Avantes UV Spectrophotometer).

Monitoring Time

Hours:Minutes:Seconds elapsed since the Device page was opened. The timer keeps running for the whole active session.

Concentration (ppm)

Current wastewater concentration from the latest spectrophotometer measurement, calculated via the Beer-Lambert Law.

Degradation (%)

Wastewater degradation percentage from the latest measurement. Formula: ((C₀ − Cₜ) / C₀) × 100.

🖥️ Monitored Hardware

Raspberry Pi 5

The system's main controller. Shows CPU usage, RAM usage, network latency, and system load. ONLINE/OFFLINE status updates automatically via WebSocket. Click the card to see full details (Device Detail).

• CPU: Cortex-A76 Quad-core • RAM: 8 GB LPDDR4X • OS: Raspberry Pi OS Bookworm • Connection: Server via Socket.io

Avantes UV Spectrophotometer

The UV-Vis absorbance measurement instrument. Shows Peak λ, latest absorbance value, USB status, and capture progress. Connected to the RPi via USB. Status shows CAPTURING while a measurement is running.

• Range: 360–2500 nm • Connection: USB to RPi 5 • Peak λ: 664 nm (Methylene Blue) • Status: CAPTURING / STANDBY

water_pump Measurement Control

Three manual control buttons for the wastewater flow and spectrophotometric measurement process. The system also runs automatically every 15 minutes.

water_pump

Fill

Activates the water pump to pump wastewater from the beaker into the spectrophotometer's cuvette. Press when ready to start a measurement cycle.

biotech

Measure

Triggers the Avantes UV Spectrophotometer to measure the wavelength and absorbance of the sample inside the cuvette. Press after the Fill step finishes. Results appear immediately on Dashboard and Analytics.

output_circle

Empty

Discharges the already-measured wastewater from the cuvette. The cuvette is emptied so it's ready for the next measurement cycle. Press after the Measure step finishes.

Workflow: Fill → Measure → Empty → repeat every 15 minutes. Each cycle produces one absorbance/concentration/degradation data point.

🔄 Live Refresh & Export Report

  • downloadExport Report – A button in the top-right corner that downloads all history data as a CSV file.
  • open_in_newTap for detail – Every device card (RPi / Avantes) can be clicked to open the Device Detail page with full telemetry and logs.

settings

Settings (User)

Account profile & system parameters

👤 Profile Tab

Update your name, organization, and location. Email cannot be changed (read-only). Click Save Profile to save.

⚗️ Parameters Tab

Configure Beer-Lambert calculation parameters:

Initial C₀ (ppm)
Initial solution concentration before the degradation process starts
Wavelength (nm)
Spectrometer measurement wavelength (default: 254 nm)
Extinction Coef.
Molar extinction coefficient of the dye (L/mol·cm)
Path Length (cm)
Optical path length of the spectrometer's cuvette

Click Save Parameters — parameters are applied immediately to all new calculations.

Admin Features

Exclusive system administrator access

⚠️ The admin panel only appears if the email contains the word admin (e.g.: admin@lab.com)

group User Management

  • View all users — table with name, email, institution, role, status, join date
  • Search & Filter — search by name/email, filter by role (Admin/User) or status (Active/Pending/Blocked)
  • Edit Role — click the ✏️ icon to change a user's role (User → Admin or vice versa)
  • Block/Unblock — click the 🚫 icon to block or reactivate a user
  • Delete User — click the 🗑️ icon to delete an account (will ask for confirmation)

  • Event Log Table — all system events: Measurement, System Event, Calibration, Error, with timestamp and status (NOMINAL/WARNING/ANOMALY)
  • Filter Log — filter by date and event type

tune Instrument Config

  • Microwave Emitter — set power range (W), current intensity via slider, toggle auto power control
  • UV Lamp Assembly — set flux density (μW/cm²), wavelength, view estimated remaining lamp life
  • Spectrometer Calibration — set C₀, path length, extinction coefficient, and measurement wavelength
  • Safety Thresholds — max particle emission limit (ppm) and minimum degradation threshold before an alarm
  • Save Config — save all changes to the server at once

Tips & Navigation

How to use the app efficiently

🧭 Sidebar Navigation

  • chevron_rightClick a menu item in the left sidebar to switch pages. The active page is marked in blue with bold text.
  • chevron_rightThe Export Data button in the sidebar is always available to download history data anytime.
  • chevron_rightThe connection status (Online/Offline) is shown in the top-right header — green = connected to the server.

🔔 Notifications

Click the 🔔 bell icon in the header to open the notification panel. Notifications appear automatically when:

  • New data arrives from the spectrometer
  • The connection to the server is lost or reconnected
  • A measurement is started, stopped, or reset
  • Data is saved successfully or an error occurs
  • Simulator data is sent successfully

🌓 Display Mode

Click the light_mode / dark_mode icon in the top-right header to switch between Dark Mode (dark, good for dim labs) and Light Mode (bright, good for well-lit environments). Your choice is saved automatically.

📱 Progressive Web App (PWA)

MICROWAT can be installed as an app on your device:

  • Chrome/Edge Desktop — click the install icon (⊞) in the address bar
  • Android Chrome — tap "Add to Home Screen" in the browser menu
  • iOS Safari — tap Share → Add to Home Screen

💡 Tips for Optimal Measurement

  • 1.Set C₀ (initial concentration) in Settings before starting your first measurement
  • 2.Use simulation mode in Dashboard to understand the data flow before connecting hardware
  • 3.Export data to CSV periodically as a backup, especially after long sessions
  • 4.Use the date filter in History to compare sessions from different days
  • 5.A SAFE status (degradation ≥70%) indicates a successful degradation process. Target at least 70%.
