Tentang MICROWAT

MICROWAT is a reactor developed by the Electrical Engineering department at ITERA to enhance the effectiveness of treating synthetic dye wastewater through microwave-assisted photocatalytic degradation. The device utilizes ZnO-Ag nanomaterials as a photocatalyst integrated with a microwave system to accelerate the degradation of pollutants, and it features a monitoring system that facilitates easier and more efficient process monitoring.

play_circle

How MICROWAT Works?

  1. 1

    The operator prepares the ZnO-Ag photocatalyst sample and the dye wastewater solution, then places them in a beaker inside the reactor.

  2. 2

    The operator turns on MICROWAT to start the photocatalytic degradation process.

  3. 3

    The degraded solution is automatically pumped to the spectrophotometer cuvette using an integrated pump system.

  4. 4

    The spectrophotometer identifies changes in the pollutant concentration in the solution.

  5. 5

    The entire process and test results are monitored via a web-based PWA and the Raspberry Pi 5 LCD screen.

Hardware Modeling

The main components include a microwave-based reactor chamber, an HPL UV lamp as the irradiation source, a ZnO-Ag photocatalyst sample, a pump system for circulating the wastewater solution, a UV-Vis spectrophotometer, a Raspberry Pi 5 as the main controller, and a touchscreen LCD screen as the user interface. All components are integrated to create a system that operates in a coordinated manner.

Software Modeling

Software modeling illustrates the workflow of the application that controls the entire operation process of MICROWAT. The web-based application allows operators to control the device, monitor system status in real-time, and display measurement and analysis results. The system is designed with an intuitive interface, making it easy to operate and monitor during the testing process.
